# ptv-departure-board
A departure board for [PTV](https://www.ptv.vic.gov.au/) trains (Melbourne, Australia) based off the different styles of board on the current network. Written in HTML, JS, and CSS


-- December 2025: The Department of Transport have discontinued this API service in favour of a newer one. I have no plans whatsoever to continue to update this project to work with the new API, feel free to yourself.
